# 🏛️ Titan Core Banking Engine

> Core Banking transaction processing engine for Titan Banking Platform. Built with Spring Boot 3.2.3 and Java 21 Virtual Threads.

Please refer to the main repository [README.md](../README.md) for full architecture details, benchmark results, and system design specifications.

### Quick Start
```bash
# Build
mvn clean package -DskipTests

# Run
mvn spring-boot:run
```
